# Мои расходы

Личный трекер трат на React + TypeScript. Работает полностью в браузере: данные хранятся
в `localStorage`, сервера нет.

![Статус](https://img.shields.io/badge/tests-22%20passed-brightgreen)

## Возможности

- Добавление, редактирование и удаление трат (удаление можно отменить).
- Переключение месяцев и фильтр по категориям.
- Итог за месяц, прогноз до конца месяца по текущему темпу.
- Круговая диаграмма по категориям и столбчатый график по последним 6 месяцам.
- Лимиты: общий на месяц и отдельные по категориям, с цветными индикаторами превышения.
- Всё сохраняется в браузере — перезагрузка страницы не обнуляет данные.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173

> Если PowerShell ругается «выполнение сценариев отключено», используйте `npm.cmd` вместо `npm`:
> `npm.cmd run dev`

## Проверка и сборка

```bash
npm test          # 22 юнит-теста
npm run build     # проверка типов + production-сборка
npm run preview   # посмотреть собранную версию
```

## Структура

| Папка | Назначение |
|---|---|
| `src/components` | Экраны и блоки интерфейса |
| `src/lib` | Логика без интерфейса: деньги, даты, расчёты, хранение |
| `src/lib/*.test.ts` | Юнит-тесты чистой логики |
| `src/types.ts` | Типы данных и справочник категорий |
| `docs/idea.md` | Описание продукта, решения и план развития |

## Решения

- Суммы хранятся в копейках (`amountKopecks`), чтобы избежать ошибок округления.
- Источник правды — один массив трат; сводка, графики и лимиты вычисляются из него.
- Ввод суммы принимает `1290`, `1 290`, `1290,50` и `1290.50`.
- Диаграммы нарисованы на SVG без сторонних библиотек.
- Диалог редактирования построен на нативном `<dialog>`: Esc и удержание фокуса — бесплатно.

## Планы

Экспорт в CSV, импорт банковской выписки, тёмная тема, повторяющиеся траты.
